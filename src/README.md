# Tic Tac Toe Game 🎮 (React)

This is a simple **Tic Tac Toe game** built with **ReactJS**. It allows two players to play the game on the same device with a clean, interactive UI and logic to check for a win or draw.

---

## 🚀 Features

- Two-player turn-based game
- Dynamic win and draw detection
- Clean and responsive UI
- Built entirely with React functional components and hooks

---

## 🛠️ Technologies Used

- ReactJS (with Hooks)
- CSS / TailwindCSS (optional)
- JavaScript (ES6+)
- Create React App

---

## 🧩 How to Play

- Players take turns to mark either "X" or "O".
- The first to align 3 marks in a row, column, or diagonal wins.
- If the board fills with no winner, it's a draw.
